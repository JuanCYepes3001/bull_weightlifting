### Features implementadas

#### #7 — Olvidé mi contraseña + cambiar contraseña desde perfil
- **Ruta nueva**: `/forgot-password` — formulario de email, llama `requestPasswordResetAction`, muestra estado de éxito
- **Ruta nueva**: `/reset-password` — formulario nueva contraseña + confirmar, usa token del callback
- **Componente nuevo**: `ChangePasswordForm` — contraseña actual + nueva + confirmar, desde perfil
- **Server Actions**: `requestPasswordResetAction`, `resetPasswordAction`, `changePasswordAction` en `auth.ts`
- **Decisión**: el callback de OAuth/reset-password comparte la misma ruta `/api/auth/callback`

#### #3 — Carrito persistente entre dispositivos (cart sync)
- **`src/app/actions/cart.ts`** — dos server actions:
  - `syncCartToServerAction(items)`: crea/encuentra el cart del usuario, reemplaza todos los items
  - `loadCartFromServerAction()`: carga el cart desde DB con join a productos/imágenes
- **`src/components/CartSyncProvider.tsx`** — cliente montado en root layout:
  - Al login: carga carrito servidor, merge con local (local gana), pushea resultado
  - Al logout: limpia carrito local
  - En cada cambio de items: sincroniza al servidor (solo si ya se hizo el merge inicial)
- **Decisión**: se usa `synced.current` como ref para no sincronizar antes de que el merge termine

#### #8 — Personalización de trusas
- Solo para productos con `category.slug === "trusas"`
- Campos: **nombre** (max 16 chars), **número** (solo dígitos, max 3), **color de estampado** (5 opciones predefinidas)
- Se muestra entre el selector de variantes y el botón de compra
- Se guarda en `LocalCartItem.customization` y se muestra en el `CartItemRow` en crimson
- **Decisión**: la customización es opcional en todos sus campos; no bloquea el add-to-cart

#### #14 — Estadísticas 7/30 días con gráficos en dashboard admin
- **`getDailyStats(days)`** en `admin.ts`: fetch de órdenes + agrupación por día en JS, pre-rellena días sin ventas con ceros
- **`SalesChart.tsx`** — componente cliente con SVG puro (sin dependencias externas):
  - 7 días: sparkline con área degradada + puntos
  - 30 días: gráfico de barras con tooltip hover
  - Toggle ingresos / órdenes
  - Toggle 7d / 30d
  - Fila resumen: total, promedio/día, mejor día
- **Decisión**: SVG puro en lugar de recharts/chart.js para no agregar deps pesadas

## Decisiones técnicas clave

- **`unknown` cast en cart.ts**: el select con join anidado de Supabase no infiere el tipo correcto cuando se encadenan múltiples niveles. Se castea `as unknown as {…}` para satisfacer TypeScript sin perder type safety en runtime.
- **Sin precio en `product_variants`**: el precio vive en `products`, no en variantes. Hay que siempre hacer join al producto para obtenerlo.
- **Supabase types desactualizados**: `admin_activity_log` y `admin_id` generan errores TS pre-existentes porque las migraciones no se han re-generado en los tipos. No bloquean el build.
