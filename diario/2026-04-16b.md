## Hallazgos resueltos (CN-004 a CN-022)

### Alta prioridad

**[CN-004]** Open redirect en auth callback — `src/app/api/auth/callback/route.ts`
- El parámetro `next` aceptaba `//evil.com` (protocol-relative URL)
- Fix: regex `^\/(?!\/)` valida que sea ruta relativa antes del redirect

**[CN-005]** Monto capturado de PayPal no verificado
- `finalizePayPalOrderAction` solo chequeaba `status === "COMPLETED"`, no el monto
- Fix: `paypal.ts` retorna `capturedAmount`; `checkout.ts` guarda `totalUSD` en cookie y verifica tolerancia ±$0.02

**[CN-006/007]** `xlsx@0.18.5` con CVEs sin patch → migrado a `exceljs`
- `src/app/api/admin/reports/orders/route.ts` completamente reescrito con ExcelJS API
- `serverExternalPackages: ["xlsx"]` eliminado de `next.config.ts`
- Comando ejecutado: `npm uninstall xlsx && npm install exceljs`

**[CN-008]** Next.js DoS — `npm audit fix` aplicado en rama `test-CN008`
- Actualizó Next.js 16.2.2 → 16.2.4 (parche disponible dentro de `^16.x`)
- Mergeado a `juank`

### Media prioridad

**[CN-009]** XSS en email templates — `src/lib/email.ts`
- Función `esc()` agregada; campos de usuario (`productName`, `size`, `color`, `full_name`, `address`, `city`, `state`) ahora escapados
- Ver [[xss-html-escape]]

**[CN-010]** Middleware admin falla abierto — `src/lib/supabase/middleware.ts`
- `get_user_role` RPC ya no swallows el error; si falla → loguea + falla cerrado

**[CN-011]** Sin CI/CD
- `.github/workflows/security.yml` — `npm audit --audit-level=high` en push/PR
- `.github/dependabot.yml` — actualizaciones semanales automáticas

**[CN-012]** Sin `.env.example`
- Creado con todas las variables requeridas
- `email.ts` y `whatsapp.ts` loguean error explícito si faltan keys (en lugar de silencio)

**[CN-013]** `listUsers()` carga toda la tabla
- `src/app/actions/users.ts` — ahora usa `listUsers({ perPage: 1000 })`
- Fix funcional real: el default de 50 hacía que usuarios en página 2+ nunca se encontraran

### Baja prioridad

**[CN-014]** Error interno de Supabase expuesto al cliente — `users.ts:52` ahora loguea + mensaje genérico

**[CN-015]** `NEXT_PUBLIC_SITE_URL` → `SITE_URL` (server-only)

## Decisiones tomadas

| Decisión | Razón |
|---|---|
| No lanzar con throw en notificaciones aunque falten keys | Notificaciones son fire-and-forget, no deben bloquear el checkout |
| Usar `perPage: 1000` en lugar de paginar en loop | La app tendrá pocos usuarios; simple y efectivo |
| Vercel Hobby plan | Gratuito, suficiente para pruebas y lanzamiento inicial |
| Resend `onboarding@resend.dev` para pruebas | No requiere dominio verificado, funciona de inmediato |
| PayPal sandbox antes de live | Probar flujo completo sin cargos reales |
