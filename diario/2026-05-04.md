## Qué hicimos

### 1. Script de importación de inventario — v3

El script `scripts/import-inventory.mjs` fue reescrito para adaptarse a la estructura real del Excel:

```
ITEM | DESCRIPTION | QUANTITY | XS | S | M | L | XL | XXL | UNIT COST | CATEGORY_GENDER | COLOR_HEX
```

**Cambios clave vs v2:**
- `DESCRIPTION` = material/tela del producto (no el color)
- `COLOR_HEX` = nombre o valor hex del color (era ignorado antes)
- `CATEGORY_GENDER` = género directo desde el Excel (no inferido del nombre)
- `getCategoryKey` ahora divide CamelCase — `CamisaClasicaLogos` → `CAMISA` → categoría `Camisas`
- `parseColor()`: acepta nombre de color (`NEGRO`) o hex directo (`#000000`)
- Validación de columnas requeridas al inicio — falla con mensaje claro si falta alguna

**Fix FK violation en SQL generado:**
El bloque CLEANUP ahora elimina en el orden correcto:
```sql
DELETE FROM order_items;   -- NOT NULL constraint, no se puede nullificar
DELETE FROM cart_items;
DELETE FROM product_images;
DELETE FROM product_variants;
DELETE FROM products;
```

Ver concepto: [[conceptos/importacion-excel-supabase]]

### 5. Swap de imagen por color en detalle de producto

**Raíz del problema:** `VariantSelector` llamaba `onSelect(null)` al seleccionar un color (sin talla aún), así el padre recibía `null` y nunca swapeaba la imagen.

**Fix:**
- `VariantSelector`: nuevo prop `onColorSelect?: (color: string) => void` — se dispara en `handleColorSelect` independientemente de la talla
- `ProductDetailClient`: `handleColorSelect` y `handleVariantSelect` actualizados
- `imageIndexForColor(color)`: dos estrategias en orden:
  1. **Por campo `img.color`** — si el import SQL pobló la columna correctamente
  2. **Fallback posicional** — `uniqueColors[N]` → `images[N]` (mismo orden de inserción)

**Fix adicional:** `getProductBySlug` ahora ordena `product_images` por `position ASC`, garantizando que `images[0]` sea siempre la primera imagen real.

**Fix tipo:** `ProductImage.color` agregado como `color?: string | null` en `src/types/index.ts`.

## Decisiones tomadas

| Decisión | Razón |
|---|---|
| Fallback posicional para swap de imagen | Las imágenes editadas manualmente en admin perdían el campo `color`; el orden de inserción es más robusto |
| `onColorSelect` separado de `onSelect` en VariantSelector | El color se conoce antes que la talla; separar permite swapear la imagen sin esperar a que el usuario elija talla |
| Bloquear eliminación de categoría con productos | Evitar huérfanos de FK; obliga a reasignar productos antes de eliminar |
| `getCategories` hace 2 queries en lugar de JOIN | El JOIN con `product_images` a través de `products` es demasiado verbose en Supabase JS; 2 queries pequeñas son más legibles y correctas |
| `isCustomizable` por slug "trusas" | Sin migración requerida; el slug es estable y controlado |
